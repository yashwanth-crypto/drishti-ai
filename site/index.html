Built for Indian MSME manufacturing

Quality inspection that runs with the internet off.

A camera watches the part. A trained model flags the defect in milliseconds. The operator is told what to do about it — in Hindi, not an English error code. All of it on one ordinary machine on the shop floor, with no cloud subscription.

Four modules, one screen

Most factory AI assumes a GPU, a cloud connection, and operators who read English dashboards. A shop machining a few thousand parts a month has none of those.

Module 1

Defect detection

A MobileNetV2 classifier trained on real casting images from a foundry in Rajkot, Gujarat. Pass, fail, or “send this one to a human”.

Module 2

Alerts in Hindi

The verdict becomes an instruction the person holding the part can act on, rather than a class label and a probability.

Module 3

Tool-wear prediction

Remaining useful life estimated from vibration and current sensors, validated only on tools the model never saw during training.

Module 4

Demand forecasting

Weekly demand per product category, with an 80% prediction interval rather than a single misleading number.

It knows when it doesn’t know

A two-class classifier has exactly two answers. Show it something it has never seen and it does not say “I don’t know” — it picks one, confidently. We measured it: random noise scores 99.9% confident.

So the system stopped trusting confidence. It measures how far an image sits from the parts it was actually trained on. Too far, and it refuses to judge — routing the part to a human with an alert that says “this part was not recognised”, not “this part is good”.

What it isn’t, yet

It is easy to make a demo look finished. This is a working proof of concept, tested honestly, and not yet run on a real factory floor.

  • No pilot has run. Nothing here has been deployed in a working shop.
  • Sensor data is replayed from a recorded dataset, not read from live hardware.
  • The casting images are real industrial data — but castings, not the CNC-turned parts we are ultimately aiming at.
  • The ROI figures in the app are design targets, not measured outcomes from a deployment.

Next: one real shop

A mounted camera, consistent lighting, and a few hundred images of one part type — labelled by the people who already inspect them. That is what turns a test-set number into a factory number. If you run a shop and this sounds useful, we would like to talk.
